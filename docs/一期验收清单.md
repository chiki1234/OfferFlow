## 可重复质量门

本机无需外部服务即可运行：

```bash
pnpm lint
pnpm test
pnpm typecheck
pnpm build
```

需要 PostgreSQL 与 MinIO：

```bash
pnpm db:migrate
pnpm db:seed
pnpm storage:ensure
pnpm test:integration
```

GitHub Actions 会启动真实 PostgreSQL 与 MinIO，执行上述集成场景，再启动 standalone 生产服务检查 `/api/health`、首页和 `/api/export`。当前本机没有 Docker/PostgreSQL/MinIO，且仓库未配置远程地址，因此“真实依赖集成已执行成功”仍需由可用运行环境或首次远程 CI 结果证明。

## 尚待外部决策

- 交互式登录方式尚未选定；当前仅实现显式的 `AUTH_MODE=local` 单用户模式，生产环境必须额外确认 `ALLOW_LOCAL_AUTH_IN_PRODUCTION=true` 才可使用固定 `APP_USER_ID`。
- 正式域名、反向代理与部署平台尚未提供；仓库已包含 standalone Docker 镜像、健康检查、稳定 Server Action 密钥与版本偏差配置入口。
