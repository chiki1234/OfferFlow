## 可重复质量门

本机无需外部服务即可运行：

```bash
pnpm lint
pnpm test
pnpm typecheck
pnpm build
```

需要 PostgreSQL 与 MinIO：

```bash
pnpm db:migrate
pnpm db:seed
pnpm storage:ensure
pnpm test:integration
```

GitHub Actions 会启动真实 PostgreSQL 与 MinIO，执行上述集成场景和双用户读取隔离断言，再启动 standalone 生产服务检查 `/api/health`、首页和 `/api/export`；健康检查同时覆盖认证配置、数据库和对象存储，运行时烟测还会断言全站安全响应头与私有导出的禁止缓存响应头。

2026-09-02 已在 Windows 便携版 PostgreSQL 18.6 与 MinIO `RELEASE.2025-09-07T16-13-09Z` 上执行成功：十份 migration、私有 Bucket、73 项 Vitest 测试、生产构建、完整业务集成场景与双用户隔离。账号密码端到端验收还覆盖访客跳转、正确登录、私人数据导出、退出、错误密码拒绝和公开注册关闭。
