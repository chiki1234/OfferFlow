# 腾讯云部署指南

本项目接入的是微信小程序 `wx.cloud` 云开发体系，使用腾讯云 CloudBase 文档数据库、云函数、云存储。无需购买 CVM、安装 MySQL/PostgreSQL、申请自己的 API 域名或把腾讯云 SecretKey 放进代码。

目前代码尚未连接任何真实云环境。账号注册、实名信息、套餐选择、环境创建、发布审核由你在自己的账号中操作；以下步骤按执行顺序排列。

## 1. 取得小程序 AppID

1. 打开 [微信公众平台](https://mp.weixin.qq.com/)，注册或登录**小程序**账号。
2. 完成平台要求的账号信息，在后台的开发设置中找到 AppID，形式为 `wx...`。
3. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，用管理员或已加入项目的开发者微信扫码登录。
4. 导入目录 `E:\CodingProject\JobHuntingWeb\wechat-miniapp`，填入自己的 AppID。选择小程序项目，使用云开发；不选择小游戏，也不导入外层网站目录。
5. 确认 `project.config.json` 的 `appid` 已换成真实 AppID。`touristappid` 仅用于导入占位，游客 AppID 不能完成本项目云端联调。

AppID 和云环境 ID 是公开配置标识，不是密钥；不要填写 AppSecret、SecretId、SecretKey。

## 2. 开通独立的云开发环境

1. 在微信开发者工具中进入“云开发”，按界面引导开通，创建专门给此小程序使用的环境，例如 `offerflow-mini`。
2. 套餐和费用以你账号的实时控制台为准，自行选择符合需求的方案，设置预算告警。
3. 记录系统生成的**环境 ID**，不要使用自己填写的环境显示名称。
4. 若从腾讯云 CloudBase 控制台创建环境，需在环境配置中关联此小程序的 AppID，使用支持微信云开发调用的环境。
5. 编辑 `miniprogram/config.js`，只填写 `env`：

```js
export const config = {
  env: '你的真实云环境ID',
  functionName: 'offerflow'
}
```

前端 `wx.cloud.init`、云函数部署目标、数据库和文件存储必须在同一环境中。[腾讯云的小程序云函数接入说明](https://docs.cloudbase.net/recipes/add-cloud-function-wechat-miniprogram)介绍了 AppID 关联与微信身份上下文。

## 3. 建立数据库及私有文件权限

### 数据库

在云开发的数据库页面创建集合：

```text
offerflow_workspaces
```

将集合权限设置为“仅管理端可读写”，或在自定义安全规则中粘贴 `cloudbase/database.rules.json`：

```json
{"read":false,"write":false}
```

保存规则。客户端所有数据操作通过云函数完成；不要设为“所有用户可读写”。首次从真实小程序访问时，云函数为该微信身份创建空工作区。无需手工插入用户或样例数据，无需额外复合索引。

### 云存储

进入存储权限设置，选择“仅创建者可读写”，或粘贴 `cloudbase/storage.rules.json` 并保存。该配置与 [腾讯云存储安全规则](https://docs.cloudbase.net/storage/security-rules) 的创建者私有模板一致。

文件由当前微信用户的客户端上传，因此保留微信创建者身份。云函数验证文件归属路径和文件内容后才把它登记进工作区。不要改成公开读取，也不要把存储规则直接套用到数据库。

## 4. 部署云函数

1. 在微信开发者工具的目录树里，右键 `cloudfunctions`，选择刚创建的云环境。
2. 右键 `cloudfunctions/offerflow`，选择“上传并部署：云端安装依赖”。前端没有 npm 依赖，不需要执行前端“构建 npm”，不需要运行外层网站的 `pnpm install`。
3. 在云函数配置中设置运行时为控制台可用的 **Node.js 20.19 或更新的受支持版本**；入口为 `index.main`，超时 **30 秒**，内存 **256 MB** 或更高。[运行环境列表](https://docs.cloudbase.net/cloud-function/runtime-support)以腾讯云控制台实际支持为准。
4. 在该函数的环境变量中新增：

| 名称 | 值 |
| --- | --- |
| `WECHAT_APP_ID` | 第 1 步取得的真实小程序 AppID |

5. 保存函数配置，等待部署完成。函数名称应为 `offerflow`，与前端配置一致。
6. 本函数是由 `wx.cloud.callFunction` 调用的普通事件云函数，不开启 HTTP 公开访问，不创建定时触发器，不配置 AI 服务或 API Key。

如果微信开发者工具无法上传，可在同一个云环境创建名为 `offerflow` 的普通云函数，将该目录中的 `index.js`、`domain.js`、`package.json`、`package-lock.json`、`config.json` 上传到函数根目录并执行云端安装依赖。不要把整个网站或整个小程序目录作为函数上传。[控制台部署说明](https://docs.cloudbase.net/cloud-function/manage)

## 5. 配置隐私指引并在手机打开

1. 在微信公众平台完善小程序隐私保护指引，如实填写求职资料、用户主动选择的简历/面试文件和 JD 图片的处理用途、存储方式、联系渠道，以及导出和删除入口。
2. 根据平台的接口申报界面声明实际使用的文件选择、相册图片选择等能力。代码使用 `wx.chooseMessageFile` 和仅相册来源的 `wx.chooseMedia`，没有麦克风、录音、通讯录或定位调用。
3. 在开发者工具选择支持隐私授权的近期稳定基础库，建议 **3.4.3 或更新版本**，编译后进入小程序。
4. 初次进入应看到三个底部入口与空工作区；添加一个岗位，退出小程序后重进，应保留该岗位。
5. 点击开发者工具“预览”，微信扫码真机体验。必须从小程序调用云函数，控制台的裸 JSON 函数测试不会带微信身份，会被拒绝。
6. 上传文件时若弹出隐私授权面板，先打开隐私指引再同意；拒绝后应仍可管理已有岗位和文本资料。

## 6. 人工验收与发布

按 [人工验收清单](./人工验收清单.md) 完成联调，尤其是两个微信身份的数据隔离、附件私有权限、多设备冲突、断网重试。当前没有任何自动测试或真机验收结果。

通过后使用开发者工具“上传”，在微信公众平台选择版本、填写真实的小程序用途和服务类目，根据平台提示完成主体、隐私及所需备案等事项，提交审核并在审核通过后发布。具体资质、类目和审核要求由平台根据账号与功能判断；本项目没有替你提交审核，也不承诺审核结果。

## 连接问题对照

| 表现 | 检查位置 |
| --- | --- |
| 服务尚未连接 | `miniprogram/config.js` 的 `env` 是否为空；是否使用真实 AppID |
| 小程序未关联此服务 | 云函数环境变量 `WECHAT_APP_ID` 是否与项目 AppID 完全一致 |
| 非法环境 / env 错误 | AppID 是否关联云环境，前端与云函数是否在同一环境 |
| 暂时无法连接 | 集合是否存在、函数依赖是否装好、函数名称和环境是否正确；查看云函数错误码日志 |
| 文件上传 / 打开被拒绝 | 云存储是否“仅创建者可读写”；文件是否为当前微信账号上传 |
| 文件内容与格式不符 | PDF/JPG/PNG 是否真实对应格式；TXT 是否为 UTF-8 且不超过 1 MB |
| 数据有更新，请刷新后重试 | 另一设备已写入；刷新完成后检查最新资料，再重新提交保留的输入 |
| 文件待保存 | 点击“重试”；若格式错误则点“放弃”，重新选择文件 |
| 资料空间已满 | 导出结构化资料并保存文件副本，清理旧岗位/资料，或按架构文档扩展数据模型 |

## 日常维护

- 在腾讯云控制台查看调用量、容量和错误码，不在日志里记录简历、问题、OpenID 或文件正文。
- 配置预算告警及符合账号需要的数据库备份策略；不要把套餐开通视作已配置备份。
- “清空所有资料”会清除当前账户的业务数据并尝试删除已登记的文件。若云存储暂时失败，“我的资料”保留清理入口，下次写入也会重试。待删队列中仍有条目时尚未完成物理删除。
- 网络恰好在文件上传成功但登记失败时中断，会在当前设备保存只含文件 ID/请求标识的恢复记录；重新打开后可以继续保存或放弃。卸载小程序/清除本地存储会丢失该恢复记录；管理员需要按数据库已登记文件与上传预约对照云存储，清理无引用的历史文件。不要直接批量删除整个存储桶。
- 本项目不发送订阅消息。日程只在小程序内显示，不会自动在后台推送提醒。
