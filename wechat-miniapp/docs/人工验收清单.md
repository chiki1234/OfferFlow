# 人工验收清单

状态：**待用户人工验收**。以下是待执行步骤，不是已通过的测试记录。

## 准备

完成部署指南，准备两个不同微信账号 A/B、两台设备、一个真实 PDF 简历、一张 JPG/PNG JD 图片和一份 UTF-8 TXT 面试材料。首次联调建议使用独立测试云环境，发布前切换到生产环境后再次确认权限。

## 完整业务闭环

| 入口 | 操作 | 预期结果 |
| --- | --- | --- |
| 首次进入 | 打开小程序 | 显示空工作区，没有样例岗位，没有 AI 入口 |
| 求职 → 添加岗位 | 新建公司、岗位、城市、薪资、JD | 保存后能在“待投递”找到，关闭重进仍存在 |
| 资料 → 经历 | 新增项目经历 | 可编辑、检索、查看全文 |
| 资料 → 简历 | 上传 5 MB 内 PDF，关联经历 | 私有保存，能预览，修改名称与关联后保留 |
| 岗位 → 编辑 | 选择投递简历并保存 | 岗位详情能直接打开所关联的 PDF |
| 岗位 → JD 附件 | 从相册选择 JPG/PNG | 详情可打开图片，删除后不再有附件引用 |
| 岗位 → 更新进度 | 改为已投递 | 求职“进行中”能找到，进展里有状态记录 |
| 岗位 → 面试 | 选择明天的固定时段 | 今日“下一步”和对应日期出现安排，岗位进入面试中 |
| 今日 → 日历 | 翻周、选择日期、点击今天 | 七天、月份和列表一致，带安排的日期显示圆点 |
| 今日 → 日程 | 在已有固定时段内再建一项 | 显示时间冲突，原安排不变；相邻不重叠时段可以保存 |
| 日程 → 调整安排 | 修改时间与地点 | 日期列表和下一步卡片更新，进展有调整记录 |
| 面试 | 创建截止时间面试并完成 | 记录为服务器完成时刻之前一小时的固定时段，进入复盘 |
| 固定时段面试 | 未开始时尝试完成 | 被阻止；已开始后能完成，完成后进入复盘 |
| 面试复盘 | 写复盘并保存 | 待复盘数量减少；面试详情保留正文，可再次编辑 |
| 已完成面试 → 记录问题 | 新增问答，关联经历 | 资料可检索，来源面试与岗位保留，经历详情列出关联问题 |
| 面试 → 面试材料 | 上传 PDF 或 UTF-8 TXT | PDF 可预览，TXT 在同层面板查看，可删除 |
| 资料 → 面试问题 → 导入 | 粘贴多行问题，含编号及重复项 | 自动去掉行首编号，仅新增未存在的完全相同标题之外的问题 |
| 岗位 → 测评 / 笔试 | 选择截止时间并完成 | 日程完成，岗位进展记录更新，时间转为实际一小时时段 |
| 快捷添加 → 待办 | 不关联岗位，设置截止时间 | 今日对应日期能找到，可以完成 |
| 岗位 → 进展 → 记录 | 写一条联系 HR 的记录 | 进展按时间呈现，退出重进保留 |
| 岗位 → 更新进度 | 改为 Offer 或已结束 | 对应筛选可见；待完成日程取消，已完成记录保留 |

## 交互与视觉

- 在小屏手机与大屏手机上查看三个入口，确认主标题、卡片、日期选择、底部导航、浮动加号和安全区不遮挡。
- 打开长 JD、长问题和很长的公司名，确认能完整阅读、不横向溢出；长表单可在键盘弹出时继续滚动。
- 从岗位跳到日程，再查看来源岗位；应该始终只有一个底部面板，关闭就回到主入口，没有多层返回栈。
- 编辑后关闭面板，应询问是否放弃；选择取消后输入内容仍存在。
- 卡片收藏按钮只收藏，不误开详情；日程完成按钮只完成，不误开详情。
- 空列表、搜索无结果、连接失败、加载中和保存中分别有可识别状态；主界面没有教程、开发注释或 AI 配置说明。

## 身份和文件权限

- A 账号创建资料，再用 B 账号打开，应是独立空工作区；B 不能看到或修改 A 的记录。
- 在受控调试中，以 B 账号调用云存储下载 A 的 fileID，必须被拒绝。即使拿到 ID，也不能公开访问。
- 从客户端直接调用数据库 SDK 读写 `offerflow_workspaces`，应被权限规则拒绝；正常云函数读写成功。
- 伪造输入中的 owner、_id、OpenID、关联 ID，不能操作其他用户的资料；云函数只能按可信微信上下文选中工作区。
- 测试一个非 PDF 改后缀的文件、大于 5 MB 的文件、非 UTF-8 TXT，不能登记为合法附件。
- 取消隐私授权后，不应上传文件，已有文本功能仍能使用；同意后可正常选择文件。

## 并发、网络和恢复

- 同一账号在设备 A/B 打开同一工作区。A 保存后，B 用旧版本编辑保存，应提示数据有更新；B 输入不丢失，刷新后再次保存才能提交。
- 连续快速点击保存只产生一次业务记录；断网后显示失败，不能显示成功或生成离线样例。
- 上传成功、最终确认前模拟断网；恢复网络后用“文件待保存 → 重试”，文件只登记一次。退出重进后恢复入口仍存在。
- 对上传格式错误选择“放弃”，可重新选择文件；不要无限重试错误格式。
- 查看日期跨月、跨年、今天没有安排、全部日程完成、多个待复盘时的展示与入口。

## 导出和删除

- 我的资料 → 导出全部资料：微信文件分享器应给出 JSON。人工检查当前用户岗位、日程、问答、经历、简历/附件 ID 和事件齐全；文件正文不在 JSON 中。
- 删除被岗位引用的简历应被阻止。解除岗位关联后删除，列表移除且私有文件被删除；云存储失败时显示清理入口。
- 删除经历后，问题本身仍保留，经历关联和简历关联解除。
- 删除岗位后，关联日程和附件移除，问题与经历保留并解除已删除来源。
- “清空所有资料”需输入“清空”确认，其他输入不会清空。操作后关闭重进为空；检查云端业务数组和文件删除状态。若出现待删除文件，执行清理直至队列为空。
- 人为填充至容量上限附近，再次保存超限内容应明确失败，既有数据不丢失，可导出及删除整理。
